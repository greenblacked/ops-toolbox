# AI tooling notes

[Ops Toolbox](../README.md) / **AI tooling notes**

Short, production-oriented notes on AI-adjacent tools that matter for platform
and workstation work: what they do, how they fit an ops workflow, and where
the risk is.

This folder is **documentation only**. It does not install agents, MCP
servers, or analysis engines.

## Conventions

- Prefer official project sources over mirrors or renamed forks.
- State legal and security boundaries explicitly; do not treat popularity as
  authorization.
- Keep recommendations concrete: when to adopt, when to avoid, and what to
  isolate.
